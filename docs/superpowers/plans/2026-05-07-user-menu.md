# User Menu Dropdown Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Зробити кнопку `···` біля імені користувача функціональним dropdown-меню (Налаштування · Тема · Вийти) і прибрати окрему кнопку шестерні з sidebar.

**Architecture:** Всі зміни — у двох файлах: `App.svelte` (стан + handlers + розмітка) і `styles.css` (нові класи + прибрати `.nav-item-settings`). Dropdown рендериться всередині `.user-footer` (position: relative), backdrop — `position: fixed` для перехоплення кліків по всьому екрану. Взаємне виключення з palette через явний виклик `palette.close()` / `showUserMenu = false`.

**Tech Stack:** Svelte 4, TypeScript, Vitest + jsdom, CSS custom properties (acta design tokens)
