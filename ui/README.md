# Legacy UI Reference

Ця папка більше не є канонічним UI для Acta.

- Runtime і збірка компілюють `ui-redesign/app.slint` через `build.rs`.
- Файли в `ui/` збережені тимчасово як довідкові legacy-артефакти під час переходу на redesign.
- Нові зміни UI потрібно вносити в `ui-redesign/`, а не сюди.
- Якщо якийсь файл із `ui/` ще потрібен, його слід або мігрувати в `ui-redesign/`, або явно позначити як legacy reference.
